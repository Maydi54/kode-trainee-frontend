# kode-trainee-frontend
# Тестовое задание Frontend-стажёра (KODE, 2025)

Веб-приложение со списком сотрудников компании, реализованное в рамках КТ2 по дисциплине «Основы IT».

## Исходное задание
[Текст задания компании KODE на GitHub](https://github.com/Hexlet/ru-test-assignments/blob/main/frontend/kode/trainee-test-frontend.md)

## Что сделано
- Отрисовка списка сотрудников с аватарами, должностями и тегами.
- Фильтрация по департаментам (Designers, Analysts, Managers, iOS, Android).
- Живой регистронезависимый поиск по имени, фамилии, тегу или должности.
- Сортировка списка по алфавиту.
- Детальная карточка сотрудника в модальном окне при клике.
- Обработка пустого результата поиска (экран «Мы никого не нашли»).

## Что не сделано и почему
- Получение данных с реального внешнего API с обработкой ошибок сети 500 — использован локальный массив моковых данных, чтобы уложиться в отведённые 6–8 часов и сосредоточиться на основном пользовательском сценарии.
- Поддержка тёмной темы и кэширование запросов — не входят в базовый сценарий поиска и просмотра карточки.

## Как запустить
Проект не требует установки зависимостей и сборщиков:
1. Склонируйте репозиторий: `git clone https://github.com/Maydi54/kode-trainee-frontend`
2. Откройте файл `index.html` в любом современном браузере (или через расширение Live Server в VS Code).

## Как проверялось
Ручное тестирование по сценариям: ввод корректных и несуществующих запросов, ввод пробелов и разного регистра в поиске, переключение вкладок отделов, открытие и закрытие модального окна по крестику и клику на фон, проверка адаптивности на ширине экрана 375px и 1280px.
